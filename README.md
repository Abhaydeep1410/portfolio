# ABHAY DEEP — THE SERIES

A streaming-inspired portfolio for **Abhay Deep**, Java Backend Engineer (Spring Boot, Microservices, Kafka, AWS).

> Layout and code are based on the "Sushmita — The Series" portfolio template by Sushmita Dasari. Not affiliated with any streaming service.

## Run it

Requires Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

## Update content

All content lives in `src/data/portfolio.ts`. Replace the resume at `public/assets/Abhay_Deep_Resume.pdf`.
Portraits: put a high-res photo in `pic1.jpeg` and a background-removed cutout in `pic.png`, then run `npm run images`.
